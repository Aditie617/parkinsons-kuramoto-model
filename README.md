Dopamine-Adaptive Kuramoto Network for Parkinson's Disease

This repository accompanies the preprint A Dopamine-Modulated Adaptive Kuramoto Network for Modeling Parkinsonian Tremor Emergence. It presents a computational framework in which dopamine depletion continuously modulates network coupling, allowing pathological beta-band synchronization to emerge naturally rather than through manually defined disease states. The project includes the manuscript, simulation code (where applicable), and supporting resources.
